# Travel Diaries

A personal travel map documenting trips through photos, routes, and moments.

Built as a self-initiated project to learn web development — using Leaflet.js, 
JavaScript, and a lot of curiosity.

**Live site:** https://nehadbhalerao.github.io/travel-diaries

---

## Trips
- 🇮🇪 Ireland 2025
  
---

## Built with
- [Leaflet.js](https://leafletjs.com/) — interactive maps
- [Leaflet.markercluster](https://github.com/Leaflet/Leaflet.markercluster) — clustered photo markers
- [OSRM](https://project-osrm.org/) — real road routing
- HTML, CSS, JavaScript

---

## What it does
- World map with clickable trip markers
- Photo pins at each location with a fullscreen image viewer
- Route drawn between stops
- Dark mode toggle
- Mobile friendly
